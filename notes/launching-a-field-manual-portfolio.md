# Launching a field-manual portfolio

## The brief

The portfolio needed to show more than a list of tools. It needed to make the connection between industrial engineering, operational work, and practical automation immediately understandable.

## The decision

Instead of a conventional gallery, the site uses the structure of a field manual: labels, process traces, evidence cards, and clear system states. The visual language supports the message that the work starts by observing what is really happening.

## What shipped

- An evidence-led KAIA process-improvement case study with clear scope language.
- Two personal automation build cases that describe operating logic without inventing client outcomes.
- A project-intake form that asks visitors to name the bottleneck before describing a solution.

## Next iteration

The next useful proof layer is richer build documentation: interface captures, before-and-after process maps, and short notes on the decisions made along the way.
