# Making contact an operating system

## The friction

Generic contact forms often create generic requests. They collect a name and a message, then leave the next step ambiguous for both sides.

## The design response

The published enquiry form asks for the organisation, the actual operating bottleneck, the website, and the expected timeline. That structure produces a more useful starting point without turning a first conversation into a long discovery exercise.

## Why it matters

Good automation work begins with context. A useful intake path gives the first conversation enough context to identify what should be mapped, clarified, or measured first.

## Operating note

The public form remains deliberately short. If the work needs more detail, the next conversation—not the initial form—should carry that burden.
